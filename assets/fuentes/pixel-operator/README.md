# Pixel Operator

Tipografía bitmap de Jayvee Enaguas (HarvettFox96), obtenida de [DaFont](https://www.dafont.com/es/pixel-operator.font). Se incluyen las variantes regular y negrita para la interfaz de la demo.

La descarga original incluye [LICENSE.txt](LICENSE.txt), correspondiente a **CC0 1.0 Universal**. Los archivos TTF se conservan sin modificar. La carpeta `assets/fuentes` centraliza las fuentes que se sirven tanto en desarrollo como en Docker.
