# Dados

`D6.gif` y `D20.gif` son los originales recibidos. Cada uno tiene 20 fotogramas de 80 ms: una pasada dura **1,6 segundos**. El movimiento usa D6; los ataques acertados muestran el resultado de D20 y D6. En fallos se reproduce la tirada sin inventar valores que el motor no publicó.

`generated/` contiene las imágenes estáticas de los botones y los tiempos derivados para integrar los GIF. La animación es presentación: el servidor decide y persiste la tirada antes de mostrarla. Los GIF también aparecen sobre el tablero compartido con el nombre del actor; el resultado numérico confirmado se revela después de la animación correspondiente.
